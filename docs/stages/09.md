# Stage 09 — Agent Roles

## Acceptance criteria

- [x] Architect/Planner produces typed non-empty plans and blocks prompt-injection instructions in repository context.
- [x] Editor/Operator dispatches only typed, approved tools through the single-writer mesh.
- [x] Independent Reviewer accepts only complete machine-readable verification evidence.
- [x] Repair is reproduce-first and capped by an attempt budget.
- [x] Tests cover prompt injection, unknown tools, failed evidence, and repair limits.

## Implementation

Added `astra_coder.agents` with Architect, Editor, Independent Reviewer, and reproduce-first bounded Repair roles. Repository context is scanned by a prompt-injection guard; the editor dispatches only typed tool names; reviewers require independent evidence fields; repair never applies a fix until reproduction succeeds.
