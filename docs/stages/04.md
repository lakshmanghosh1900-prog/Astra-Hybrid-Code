# Stage 04 — Hybrid Model Gateway

## Acceptance criteria

- [x] A registry represents local and remote models with cost/context metadata.
- [x] Ollama and OpenAI-compatible adapters use typed requests and never expose keys in errors.
- [x] A deterministic classifier selects a minimum model tier.
- [x] Routing prefers eligible local models and cascades to remote models only when allowed.
- [x] Retries, circuit breaking, and cost/token metering are bounded.
- [x] Tests cover provider failure, retry, local-first routing, remote denial, and circuit open behavior.

## Implementation

Added `astra_coder.gateway` with typed model/provider contracts, Ollama and OpenAI-compatible HTTP adapters, deterministic task classifier, local-first cascade routing, retry bounds, circuit breakers, and a cost/token meter.
