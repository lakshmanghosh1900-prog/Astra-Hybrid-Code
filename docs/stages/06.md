# Stage 06 — Tool Mesh

## Acceptance criteria

- [x] Read, write/patch, shell/test delegation, git, and search tools have strict schemas.
- [x] Path traversal, absolute paths, symlink escapes, and expected-base mismatches fail closed.
- [x] Command inputs are argv-based, reject shell interpreters/NULs, and use no shell interpolation.
- [x] The default tool mesh never runs agent commands on the host.
- [x] File writes are serialized and atomically replaced.
- [x] Tests cover adversarial paths, command injection shapes, delegation, and write conflicts.

## Implementation

Added `astra_coder.tools` with strict Pydantic schemas, canonical path/symlink guards, expected-base hash checks, serialized atomic writes, bounded search/read operations, an argv-only command schema with an executable allowlist, and a default no-host executor.

## Evidence

```text
.venv/bin/python -m pytest
# 33 passed
.venv/bin/python -m ruff check src tests
# passed
.venv/bin/python -m ruff format --check src tests
# passed
.venv/bin/python -m mypy src
```

Adversarial tests cover traversal, absolute paths, symlink escape, NUL/shell interpreter/inline-code command shapes, outside-root writes, and no-host execution by default.
