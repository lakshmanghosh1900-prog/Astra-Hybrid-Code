## Release blockers

- This container has Python 3.11, not the locked Python 3.12.2 runtime.
- Docker/Docker Compose is not installed, so image build, sandbox network isolation, Compose startup, and clean-container verification could not run.
- `npm audit --omit=dev --audit-level=high` reports one critical advisory for the locked Next.js 14 dependency; its suggested fix is a later major, which would violate the locked stack.
- The 70-task agent baseline is 0/70 because a live model-backed executor/provider is not enabled in this offline workspace; the contract smoke report is explicitly not a model-quality claim.
- `gh` is not installed/authenticated in this environment, so no GitHub push or release tag was attempted.

No `v1.0.0` tag should be created until these blockers are resolved and the same checks are rerun on the target clean Linux environment.
