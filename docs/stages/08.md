# Stage 08 — Git Safety

## Acceptance criteria

- [x] Each task is created in an isolated Git worktree from a recorded base revision.
- [x] Checkpoints commit only task-worktree changes.
- [x] Diff and status evidence are scoped to the task.
- [x] Rollback refuses to operate on the user's root worktree and removes only the task worktree.
- [x] A critical test proves pre-existing uncommitted user changes survive rollback.

## Implementation

Added `astra_coder.git_safety` with task-id validation, isolated detached worktrees, task-scoped checkpoints, base-revision diffs, status evidence, and rollback that refuses the user's root worktree. Checkpoint commits use an explicit Astra identity so local setup does not require global Git configuration.

## Evidence

```text
.venv/bin/python -m pytest
# 40 passed
.venv/bin/python -m ruff check src tests
# passed
.venv/bin/python -m ruff format --check src tests
# passed
.venv/bin/python -m mypy src
# Success: no issues found in 11 source files
```

The critical integration test creates a dirty user worktree, changes a separate task worktree, rolls the task back, and asserts the user's dirty file is byte-for-byte preserved.
