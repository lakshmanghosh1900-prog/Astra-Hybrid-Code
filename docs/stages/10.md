# Stage 10 — Verification Engine

## Acceptance criteria

- [x] Tests, lint, type-check, Semgrep, and gitleaks are first-class required gates.
- [x] Gate status distinguishes passed, failed, unavailable, and timed out.
- [x] Results include commands, bounded output, findings, duration, and evidence hashes.
- [x] A summary cannot be successful if a gate is missing/unavailable/failed.
- [x] The default runner fails closed instead of running agent commands on the host.
- [x] Tests prove the no-false-success rule.

## Implementation

Added `astra_coder.verification` with required quality/security gate specifications, fail-closed runner boundary, status parsing, bounded outputs/findings, duration and per-gate evidence hashes, summary hashing, and an explicit `require_success` guard.

## Evidence

```text
.venv/bin/python -m pytest
# 50 passed
.venv/bin/python -m ruff check src tests
# passed
.venv/bin/python -m ruff format --check src tests
# passed
.venv/bin/python -m mypy src
# Success: no issues found in 13 source files
```

Tests prove that failed, unavailable, and timed-out gates cannot become success.
