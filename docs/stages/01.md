# Stage 01 — Scaffold & CI

## Acceptance criteria

- [x] Python 3.12 and Node.js versions are pinned.
- [x] Application dependencies, development dependencies, and a lockfile are declared.
- [x] A safe environment contract, CLI doctor command, API health endpoint, Dockerfile, and README exist.
- [x] Offline tests, lint, typecheck, and security gate commands are reproducible.
- [x] CI runs the canonical checks without secrets.

## Implementation

Implemented the reproducibility baseline, environment-only configuration loader, `astra doctor`, FastAPI health endpoint, package metadata, lockfile, Makefile, Dockerfile, Semgrep policy, gitleaks configuration, CI workflow, and initial tests.

The environment currently lacks Python 3.12, Docker, Semgrep, and gitleaks. The repository pins Python 3.12 and CI installs/runs the release security tools; those gates are recorded as unavailable locally rather than represented as passed.

## Result

Stage 01 implementation is complete and committed. Release verification remains dependent on a Python 3.12/Docker/security-tool environment.
