# Stage 05 — Repository Intelligence

## Acceptance criteria

- [x] A tree-sitter index extracts symbols from supported source files.
- [x] Imports/dependencies and file hashes are captured.
- [x] Search uses ripgrep when present and a bounded deterministic fallback otherwise.
- [x] Context selection is relevance-ordered and budget-capped.
- [x] Incremental indexing reuses unchanged file records.
- [x] Tests cover symbol extraction, dependency indexing, bounded search, invalid patterns, and context truncation.

## Implementation

Added `astra_coder.intelligence` with tree-sitter Python symbol extraction, import dependency records, SHA-256 incremental snapshots, bounded ripgrep/fallback search, and relevance-ordered context budgeting.

## Evidence
