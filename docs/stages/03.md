# Stage 03 — Policy Engine

## Acceptance criteria

- [x] RBAC maps roles to typed actions and unknown roles fail closed.
- [x] Risk tiers determine approval requirements.
- [x] Reviewer/admin approval is explicit and cannot be self-granted by a developer.
- [x] Kill switch blocks mutations while allowing safe status/cancel operations.
- [x] Per-task and daily token/cost budgets are enforced.
- [x] Approved repository roots reject outside paths.
- [x] Tests include role, bypass, approval, kill-switch, budget, and path-boundary cases.

## Implementation

Added `astra_coder.policy` with role-to-action permissions, risk-tier approval gates, explicit reviewer approval, admin kill switch, per-task/daily token and cost budgets, and repository-root path checks.
